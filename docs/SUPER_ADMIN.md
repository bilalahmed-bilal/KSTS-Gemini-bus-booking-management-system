# KSTS Super Admin Panel

## Overview

Super Admin is the highest authority level in the KSTS Bus Booking Management System.

Super Admin controls all companies, users, permissions, system settings and overall platform operations.

---

# Super Admin Responsibilities

## 1. Authentication & Security

Super Admin can:

- Login securely
- Logout
- Session management
- Password protection
- Change password
- Reset password
- Account security management

Future:

- Two Factor Authentication
- Email verification
- Login device tracking
